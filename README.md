# Weather Forecast — AI Climate Intelligence Platform

Weather Forecast is a next-generation AI-powered climate intelligence platform delivering futuristic environmental analytics, realtime atmospheric simulations, and predictive weather forecasting through cinematic immersive technology.

## 🚀 Features

### 🧠 AI Climate Intelligence
- **AI-Powered Future Weather Intelligence:** Experience next-generation climate forecasting powered by Artificial Intelligence, Machine Learning, and realtime atmospheric simulations.
- **Neural Temperature Forecast:** Realtime AI-generated future temperature analysis powered by LSTM climate forecasting models.
- **Rainfall Probability Engine:** Advanced precipitation prediction using atmospheric pressure mapping and humidity evolution.
- **Storm Detection System:** Realtime thunderstorm and cyclone risk analysis with AI confidence scoring.
- **AQI Intelligence:** Predict future air quality trends and pollution movement using environmental AI models.

### 🌍 Immersive Visualization
- **Realtime Earth Climate Simulation:** Visualize Earth’s atmosphere in realtime through immersive 3D satellite simulations featuring storm movement, global heatmaps, cloud layers, and wind patterns.
- **Advanced Storm & Radar Tracking:** Track rain systems, lightning zones, cyclone movement, and atmospheric turbulence through futuristic radar visualization technology.
- **Global Weather Intelligence Network:** Interactive world map to explore realtime weather conditions and AI climate predictions from every region on Earth.

### 🤖 Smart Interactions
- **Meet Your AI Climate Assistant:** Ask questions about weather, travel conditions, farming guidance, or storm risks through an intelligent AI assistant trained on atmospheric datasets.
- **Atmospheric Simulation Modes:** Experience different weather modes including Sunny, Rain, Thunderstorm, Snow, and Night modes with volumetric effects.
- **Smart Environmental Alerts:** Receive instant AI-generated alerts for storm warnings, rain predictions, heatwaves, AQI hazards, and flood threats.

## 🛠 Tech Stack

- **Frontend:** Next.js 14, React 18, Framer Motion (for smooth animations), Lucide React (icons).
- **Backend:** Node.js, Express, Socket.IO (for realtime updates).
- **Styling:** CSS variables, Glassmorphism, Neon aesthetics.
- **Libraries:** Globe.gl / Three.js (for 3D Earth), D3.js (used in interactive components).

---

## 📡 Data Sources & APIs

- **Live Weather Data:** Powered by [OpenWeatherMap API](https://openweathermap.org/api). Provides current weather, forecasts, and historical data.
- **Artificial Intelligence:** Powered by [Google Gemini API](https://ai.google.dev/). Drives the AI voice assistant and predictive weather insights.
- **Radar Data:** Integrated via Windy iframe embeds for high-fidelity storm tracking.

## 💻 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- NPM

### Installation

1. Clone the repository or navigate to the project folder.
2. Install dependencies for both frontend and backend:
   ```bash
   # In the backend directory
   cd backend
   npm install

   # In the frontend directory
   cd ../frontend
   npm install
   ```

3. Set up environment variables:
   - Create a `.env` file in the `backend` directory.
   - Add your API keys:
     ```env
     OPENWEATHER_API_KEY=YOUR_KEY
     GEMINI_API_KEY=YOUR_KEY
     ```

### Running the Project

You can run both servers using the following commands in their respective directories:

```bash
# Start Backend (Port 5000)
cd backend
npm run dev

# Start Frontend (Port 3000)
cd frontend
npm run dev
```
