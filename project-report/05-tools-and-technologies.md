# Chapter 5: Tools and Technologies

## 5.1 Next.js 14
-   **Role**: Frontend Framework.
-   **Usage**: Used for building the user interface with React server components and client components. It provides efficient routing and optimized loading.

## 5.2 Node.js + Express
-   **Role**: Backend Gateway.
-   **Usage**: Used to create the main server that handles API requests from the frontend, manages environment variables securely, and communicates with external services like Gemini.

## 5.3 Python + FastAPI
-   **Role**: AI/ML Engine (Simulated).
-   **Usage**: Used to define a separate service for handling machine learning tasks and serving predictions. FastAPI provides high performance and automatic documentation.

## 5.4 Styling: Tailwind CSS & Custom CSS
-   **Role**: Visual Design.
-   **Usage**: Tailwind CSS was used for rapid utility-first styling, while custom CSS properties were used to define the core "glassmorphic" design system (blur effects, gradients, glows).

## 5.5 Visualization: Globe.gl & Framer Motion
-   **Role**: Interactive Elements.
-   **Usage**:
    -   **Globe.gl**: Used to render the interactive 3D Earth map with city points and arcs.
    -   **Framer Motion**: Used for high-quality, physics-based animations across the site (fade-ins, scale-ups, floating panels).

## 5.6 External APIs
-   **Google Gemini API**: Used to generate intelligent, context-aware responses for the chat assistant.
-   **OpenWeatherMap API**: Used to fetch live atmospheric data, daily forecasts, and air quality metrics.

## 5.7 Git and GitHub
-   **Role**: Version Control and Collaboration.
-   **Usage**: Git was used to track changes locally. GitHub served as the remote repository, enabling easy sharing and deployment triggers.
